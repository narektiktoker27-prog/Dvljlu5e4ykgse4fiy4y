# CamPhish Railway

A Telegram bot for capturing media remotely using a web interface.

## Features
- 📷 **Photo Capture**: Front and Back camera support.
- 🎥 **Video Capture**: Record short video clips.
- 🎤 **Audio Capture**: Record microphone audio.
- 📍 **GPS Location**: Retrieve target coordinates.
- 🌐 **WebRTC IP**: Extract public IP via WebRTC and HTTP fallback.
- 💀 **Aesthetic UI**: Black screen with red symbols and invisible capture element.

## Deployment on Railway

1. **Create a new project** on [Railway.app](https://railway.app).
2. **Connect your GitHub repository** containing the `CAMPHISH-Railway/` folder.
3. **Set Environment Variables**:
   - `BOT_TOKEN`: Your Telegram Bot API token.
4. **Deploy**.

## Usage
Once deployed, the bot will be online. Add the bot to your Telegram and send `/start`.
- Enter the password: `qopakany100%` (or change it in `webphish10.py`).
- Select a mode from the menu to generate a link and capture data.
